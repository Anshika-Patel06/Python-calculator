# 🧮 Python Calculator Project

A simple command-line calculator developed using Python. This project performs mathematical operations using conditional statements such as `if`, `elif`, and `else`.

## 📌 About the Project

This is a beginner-level Python project that allows users to enter two numbers and select an arithmetic operation. The calculator displays the result based on the selected operator.

The project focuses on understanding Python conditional statements and basic arithmetic operations.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Modulus
- ** Power
- // Floor Division
- Division-by-zero error handling
- Invalid operator handling

## 🚀 How to Run

**Step 1: Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 2: Navigate to the project directory**

```bash
cd Python-Calculator
```

**Step 3: Run the program**

```bash
python3 calculator.py
```
